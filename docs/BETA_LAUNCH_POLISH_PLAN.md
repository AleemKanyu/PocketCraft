# PocketCraft Beta Launch Polish Plan

## Scope For Tonight

- Keep Bedrock internet relay work out of this beta.
- Focus on clear Java join flow, LAN Bedrock guidance, and support/feedback visibility.
- Make the app explain what is ready and what is still limited.

## Must-Have Polishes

1. Beta notice on first launch and version picker.
2. Clear join instructions with separate Java and LAN Bedrock paths.
3. Status chips/cards that say whether the server and bridge are actually ready.
4. Feedback entry that includes logs and a short issue report flow.
5. Any remaining visual cleanup that affects trust at launch.

## Nice-To-Have If Time Remains

- A one-tap copy/share action for join addresses.
- A small launch checklist in the app.
- A stronger empty/error state when internet relay is unavailable.

## Explicitly Deferred

- Bedrock over internet relay.
- UDP relay implementation.
- Any relay-side API redesign.

## Recommended Launch Order

1. Beta banner / limitation notice.
2. Join address clarity.
3. Status visibility.
4. Feedback/logs.
5. Cosmetic cleanup.
