# PocketCraft Update Highlights

- Smoother online play with lower ping for Java players.
- Better server performance while flying, moving fast, or loading new chunks.
- Improved connection stability for online servers.
- Built-in plugin support has been improved for better Java compatibility.
- Server settings now support up to 50 players.
- View distance and simulation distance now save more reliably.
- New themes and smoother animations for a better overall experience.
- Improved dark mode and polished parts of the app UI.

Thank you for using PocketCraft!
