# PocketCraft 1.5.0 Release Notes

- Lower Java ping and smoother relay performance.
- Better server stability during chunk loading, flying, and fast movement.
- Improved relay handling and cleanup for more reliable online joins.
- ViaVersion is now bundled and allowed for better Java compatibility.
- Support for up to 50 players.
- View distance and simulation distance now save more reliably.
- Improved dark mode, plus new themes and smoother animations.

This update focuses on making online servers feel smoother and more stable, especially for Java players.
